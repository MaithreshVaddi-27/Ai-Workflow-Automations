# Automation Anywhere (RPA)

[Automation Anywhere](https://www.automationanywhere.com) is the RPA platform I used here — the right fit for work that's purely rule-based (read a row, take a fixed action) with no reasoning or judgment call for an LLM to make.

| Project | Trigger | What it does |
|---|---|---|
| [Email Notification System](email-notification-system) | Reads an Excel source file | Sends automated email reminders per row |
